# Mascote-Digital
O **Mascote Digital** é um projeto que tem como objetivo apresentar uma nova forma de **interface interativa e divertida** entre o usuário e uma possível **Inteligência Artificial (IA)**.  
Além de **informar** e **ajudar**, o mascote também busca **entreter**, tornando a experiência do usuário mais envolvente e diversa.

---

## 🎯 Objetivo  

Criar uma ferramenta que vá além do conceito tradicional de IA — que normalmente se limita a responder perguntas — oferecendo também **interatividade**, **animações** e **personalidade**, para que o usuário sinta que está conversando com um **companheiro digital**.

---

## 💡 Funcionalidades (planejadas / implementadas)  

- 💬 Interação em tempo real com o usuário  
- 🎨 Interface animada e personalizável  
- 🤖 Respostas inteligentes e adaptáveis  
- 🎮 Elementos lúdicos para tornar o uso mais divertido  
- 🌈 Temas visuais baseados em diferentes mascotes  

---

## 🛠️ Tecnologias Utilizadas  

- **HTML5**  
- **CSS3**  
- **JavaScript**  

> O projeto está sendo desenvolvido com foco em **design responsivo**, **animações suaves** e **experiência do usuário (UX)**.
